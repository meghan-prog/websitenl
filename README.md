# Meghan Eckenbach

De officiële website van Meghan Eckenbach. Gebouwd rondom The Legacy Loop Method en het ecosysteem van gepersonaliseerde producten.

**Live:** [meghaneckenbach.com](https://meghaneckenbach.com)

---

## Over deze site

Dit is de homepage van Meghan Eckenbach, business automation strategist en bedenker van The Legacy Loop Method. De site is gebouwd in pure HTML en CSS, zonder build proces of frameworks. Eenvoudig te onderhouden, snel te laden, en direct te deployen via Cloudflare Pages.

```

├── meghan-3.png        Hero foto

```

## Wat staat er op de site

- **Hero** met The Legacy Loop Method als signature framework
- **Het probleem** dat wakkere ondernemers herkennen
- **The Legacy Loop Method** in vier fases: Vangen, Vormen, Verbinden, Verdienen
- **Het ecosysteem** met de vijf elementen: Intake, Diagnose, Advies, Feedback, Follow-up
- **De Legacy Scan** als entry product (€47, normaal €97)
- **Drie routes**: Scale in Touch DWY, Scale in Touch DFY, Partner
- **Over Meghan**, testimonials en de Winst Scan call to action

## Brand

- **Kleuren:** Rich Mahogany (#2E0E02), Pearl (#E9DFD3), Chestnut (#8B271E), Gold (#C9A84C)
- **Typografie:** Anton (headlines), Oswald (labels en navigatie), Bodoni Moda (body)

## Technisch

Deze site gebruikt:

- Pure HTML en CSS (geen frameworks)
- Google Fonts (Anton, Oswald, Bodoni Moda)
- Inline SVG voor de mockups en visualisaties
- Vanilla JavaScript voor scroll animaties en parallax
- Geen build proces nodig

## Lokaal bekijken

Open `index.html` direct in je browser. Geen server nodig. Alle assets zijn relatief gelinkt, dus zolang de PNG bestanden in dezelfde map staan werkt alles.

## Deployen via Cloudflare Pages

Deze repository is gekoppeld aan Cloudflare Pages. Elke push naar de `main` branch deployt automatisch naar productie binnen ongeveer 30 seconden.

**Build instellingen in Cloudflare:**
- Framework preset: None
- Build command: leeg
- Build output directory: leeg (of `/`)
- Root directory: leeg

## Aanpassingen maken

Voor kleine wijzigingen kun je de bestanden direct in GitHub bewerken via de web interface. Klik op een bestand, klik op het potlood-icoontje rechtsboven, maak je wijziging, scroll naar beneden en klik op "Commit changes". Cloudflare deployt het binnen een minuut.

Voor grotere wijzigingen download je de bestanden lokaal, bewerk je ze in een editor zoals VS Code, en push je ze terug naar GitHub.

## Foto's vervangen

Wil je een foto vervangen? Upload de nieuwe foto met dezelfde bestandsnaam (`meghan-3.png` etc.) en commit. De site wordt automatisch geüpdatet. Houd het formaat ongeveer gelijk (portret, hoge resolutie) voor het beste resultaat.
